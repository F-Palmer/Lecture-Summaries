> Machine Learning Goal:
> The Goal is to make predictions based on features learned from data. 

> Data Mining: 
> The Goal is to discover unknown properties in data. 

## Categories of Machine Learning Algorithms 

> Supervised ML:
> Learn relationship between input data and target variable with labeled training data.

> Unsupervised ML: 
> Discovering patterns in a given set of data points without labeled data

> Reinforcement Learning: 
> Reinforcement learning is a method for solving sequential decision problems 
> Games (chess)

## Challenges of ML 

1. Availability of training data
2. Representative training data 
3. Quality of training data 
4. The right machine learning algorithm
5. The right features
