## Ensemble models
Ensemble models can compensate for individual disadvantages and produce a better overall model

### Bagging (Bootstrap aggregating)
Same basic models, different training data sets

1. Generate B datasets from training data using bootstrapping
2. Learn B individual basic models in parallel on these data sets

Parameter number of models does not lead to overfitting

### Bootstrap 

- New dataset has the same size as the original dataset
- Fill the new dataset by randomly selecting samples form the original dataset
- Some samples may be selected multiple times

Some datapoints might be missing from some of the datasets-> Out of Bag data -> use for validation

### Random forest
1. Generate bootstrap samples and train decision trees
	1. When training individual trees only a randomly selected sample of m features is considered (typically $\sqrt p$)

Why? 
	If there is a very strong feature it will show up as the first split on almost all trees
		-> Predictions are highly correlated

Feature importance
- how much was IG improved on average for all splits in which the feature was used
- weighted by how many data points where associated with the split (how deep the split is)

### Boosting 
1. train decision tree on all training data
2. Train another decision tree focusing on the data points where the performance of the prev tree was poor (sequential)
3. Combine the prediction of all trees

#### AdaBoost

| Random Forest                                             | AdaBoost                                                                                                                         |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| each tree same vote                                       | Different vote                                                                                                                   |
| parallel generated by<br>independent boostrapped datasets | The stumps are<br>sequentially generated<br><br>The error made by a<br>stump will influence how<br>to generate the next<br>stump |
|                                                           | depth = 1 decision stumps                                                                                                        |

Weight for each Datapoint in each iteration
-> higher weight for errors in prev iteration

1. Initial predictor
2. calc the total error so the sum of the weights of the datapoints where an error happend
   $r_j = \sum^m_{i=1} w_j, \space \texttt{where} \space \hat{y_i} != y_i$
3. calc the weight the predictor gets in the final prediction
   $\alpha_j = \eta \ln{\frac{1-r_j}{r_j}}$ eta is a hyperparamter 
4. update the weights of all datapoints
$$w_i =
\begin{cases}
w_i, & \text{if } \hat{y}_i = y_i,\\[6pt]
w_i \cdot e^{\alpha_j}, & \text{if } \hat{y}_i \ne y_i
\end{cases}$$
5. normalize the weights
